# Вишнёвый гардероб

Онлайн-гардероб со стилистом. Работает как обычный сайт на GitHub Pages: без сервера, без регистрации и без платного API.

## Как это работает

- **Разбор типажа.** Человек загружает свои фото на сайт, сайт готовит запрос, запрос вместе с этими же фото отправляется в [claude.ai](https://claude.ai) (подойдёт бесплатный аккаунт), а ответ вставляется обратно. Сайт показывает цветотип, типаж, палитру, цвета «не у лица», советы и метки признаков прямо на фото с оттенками, снятыми с фото.
- **Сегодня.** Погода по городу (Open-Meteo, без ключа) и 3 образа из своих вещей под неё. «Надену это» отмечает образ в календаре.
- **Статистика.** Календарь образов, счётчики носки, «давно не надевала», цена за выход (если указать цену вещи), блок «Чего не хватает» с приоритетом по числу новых образов и вишлист.
- **Капсулы.** 10–12 вещей под поездку, работу или неделю с максимумом сочетаний, чек-лист для сборов и примеры образов.
- **Мои вещи.** Фото, категория, цвет, сезон и стиль. Заполнить карточку по фото можно тем же способом через Claude.
- **Конструктор.** Ячейки образа, оценка сочетания, «Собрать случайно» и «Подобрать образы через Claude» из своих вещей под повод и погоду.
- **Образы и копия гардероба.** Сохранённые образы; кнопки «Скачать копию» и «Загрузить копию» на вкладке «Мой типаж».

Все данные, включая фото, хранятся в браузере пользователя (IndexedDB) и никуда с сайта не отправляются. В Claude фото попадают, только когда человек сам прикладывает их в своём чате.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html`, `styles.css` | Страница и оформление |
| `app.js` | Интерфейс |
| `bridge.js` | Запросы для Claude и разбор его ответов |
| `db.js` | Хранилище в браузере, экспорт и импорт |
| `catalog.js` | Категории, цвета, стили, 12 цветотипов |
| `logic.js` | Погода, подбор образов, статистика носки, пробелы гардероба, капсулы |
| `pins.js` | Примеры пинов Pinterest для каждого цветотипа |
| `GeistMono.ttf` | Шрифт Geist Mono (лицензия SIL OFL, `GeistMono-OFL.txt`) |
| `check.js` | Проверка разбора ответов: `node check.js` |

## Публикация

Settings → Pages → Build and deployment → **Deploy from a branch**, ветка `main`, папка `/ (root)`. Сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.
